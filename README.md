# Neon Sprint: Cyber Protocol ⚡🛡️🎮

**Neon Sprint: Cyber Protocol** is a high-octane, cyberpunk-themed endless runner built as a hybrid Android application. It combines a high-performance HTML5 Canvas game engine with a native Android wrapper to provide an immersive mobile gaming experience.

## 🚀 Features

-   **Intense Gameplay:** Navigate a neon-lit cyber grid, dodging obstacles and collecting Nanites.
-   **Hybrid Architecture:** Seamless integration between a JavaScript/Canvas game engine and native Android (Kotlin).
-   **Cyber Vault & Economy:** Collect 50 free Nanites to start. Upgrade your vault using the integrated payment gateway to continue your run.
-   **Razorpay Integration:** Secure, real-money transactions for in-game upgrades.
-   **Immersive Audio:** Procedural web-audio SFX and a synthwave BGM that reacts to your speed.
-   **Immersive Mode:** Uses modern Android `WindowInsets` APIs for a full-screen, distraction-free experience.

## 🛠️ Technical Stack

-   **Frontend:** HTML5, CSS3 (JetBrains Mono Typography), JavaScript (Canvas API).
-   **Android:** Kotlin, WebView, JavascriptInterface, Razorpay Android SDK.
-   **Build System:** Gradle (Kotlin DSL) with Version Catalog.

## 📥 Setup & Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/neon-sprint-cyber-protocol.git
    ```
2.  **Open in Android Studio:**
    -   Select "Open an Existing Project" and point to the root directory.
3.  **Configure Razorpay:**
    -   Open `MainActivity.kt`.
    -   Replace `rzp_live_hMAEYRuCJZOsA5` with your actual Razorpay Key ID.
4.  **Build & Run:**
    -   Connect an Android device or emulator and click "Run".
